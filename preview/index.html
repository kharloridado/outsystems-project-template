Local component preview — real OutSystems UI base, brand theme, block overrides.

Getting started

  1. git submodule update --init — then pin vendor/outsystems-ui to the OutSystems UI version your target ODC environment actually runs.
  2. npm run build:osui — compile the framework base (layer 1).
  3. npm run build:theme — build the brand theme, both pastes (layer 2).
  4. npm run preview — serve this page and check it in a real browser.

Add a specimen section per component as you build it. Restyle the native widget wherever the framework already has one: drop the real widget markup in, give it your ExtendedClass, and confirm the override actually wins.
